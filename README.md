# General Web 🌐

**General Web** is a simple website project I created as part of my **GitHub and web development practice**. The main purpose of this project was to improve my understanding of how websites are structured, developed, and managed using Git and GitHub.

This project allowed me to practice working with basic web technologies while also learning how to organize a project, manage files, make changes, and upload my work to a GitHub repository.

## 🎯 Purpose of the Project

The main goals of this project were to:

* Practice building a basic website
* Improve my understanding of HTML, CSS, and web development fundamentals
* Learn how to organize a web project properly
* Practice using Git for version control
* Learn how to create and manage a GitHub repository
* Understand the basic workflow of making changes and pushing them to GitHub
* Build practical projects that can be added to my development portfolio
